How BUSHWHACKER Works • MDL Math & FAQ

Stage 0 — Alignment, Taxon & Dual-Entropy Site Coherence QA Input: FASTA / PHYLIP / NEXUS / .bwz
Audits alignment dimensions, gap/ambiguity fractions, and identical sequence duplicates. When coding mode is active, Stage 0 downweights rapidly saturating 3rd-codon-position transitions via dual-entropy coherence weights (w_s) so synonymous saturation cannot drown out deep cladistic splits, and computes the exact zero-split Star-Tree null code length L(D | T_star).
Effective Sites: L_eff = ∑ w_s • Star-Tree Null: all terminal mutations transmitted independently from root
Stage 1 — 64-Site Bit-Plane SIMD Tree Induction & Polytomy Calibration Output: Calibrated Tree T*
Packs 64 alignment sites per 64-bit machine word across four nucleotide bit-planes and evaluates candidate splits via hardware POPCNT Fitch parsimony and Subtree Pruning & Regrafting (SPR). Every internal branch must pay its exact topological split header L_topo(k_u, k_v) plus its combinadic mutation index ln C(L_eff, m_e). Any split whose parsimony savings fail to beat this cost is deterministically contracted into an explicit multi-way polytomy hub.
Split Retained iff: ΔL_data(e) > L_topo(k_u, k_v) + ln 2 + L_N(m_e) + ln C(L_eff, m_e) + m_e ln 3
Stage 2 — Reticulate Shunt Peeling (SPARSE Convergence vs. INTERVAL HGT) Output: Phylogenetic Network G*
Scans residual homoplasies across the induced tree for pairs of non-sister clades that share parallel derived states. Evaluates two competing prefix codes for the affected site mask: a contiguous INTERVAL block header (capturing horizontal gene transfer and recombination) and a SPARSE combinadic subset index (capturing site-specific adaptive convergence such as mammalian echolocation in Prestin).
Admits Shunt iff Net MDL Gain ΔL_net = Data Savings − Endpoint Header (2 ln |V|) − min(L_interval, L_sparse) > 0
Stage 3 — Standalone HTML Dossier & Lossless .bwz Compression Output: Archival & Publication Suite
Synthesizes a self-contained HTML publication dossier and optionally compresses the entire alignment + induced phylogenetic graph into a bit-for-bit lossless .bwz binary archive using causal preorder phylogenetic arithmetic coding.
Lossless .bwz verification: decompress_bwz(compress_bwz(D, G*)) == D (100% bit-identical)
Combinadic Branch Index ln C(L_eff, m_e) Exact Marginal Likelihood
Specifies which m_e sites mutated out of L_eff effective positions along branch e. By Stirling's identity, ln C(L_eff, m_e) equals the exact negative log-marginal likelihood of m_e mutations after analytically integrating out the unknown continuous branch length — vanishing identically when m_e = 0.
L_branch(m_e) = ln 2 + L_N(m_e) + ln C(L_eff, m_e) + m_e ln(|Σ| − 1)
Polytomy Resolution Tax L_topo(k_u, k_v) Zero-Branch Contraction
Resolving a d = k_u + k_v-way polytomy into two sub-nodes of degrees k_u ≥ 2 and k_v ≥ 2 requires transmitting the bipartition size and the exact subset of incident lineages. Zero-mutation branches save 0 nats of data but cost L_topo + ln 2 > 0, guaranteeing automatic contraction.
L_topo(k_u, k_v) = ln⌊(k_u+k_v)/2 − 1⌋ + ln C(k_u+k_v, k_u) − I(k_u=k_v) ln 2
Conditional Local Split & Shunt Posterior Plocal Local Calibration
Because description lengths in nats represent negative log-probabilities under the universal prefix prior, a net MDL compression gain of ΔLe nats gives the conditional local two-hypothesis posterior P_local = 1 / (1 + exp(−ΔL_e)) against contracting edge e (or omitting a shunt) conditioned on the fixed surrounding graph. High-confidence splits (P_local ≥ 99%) are well-calibrated, whereas intermediate values are optimistic because competing topologies are not marginalized.
P_local = 1 / (1 + exp(−ΔL_e)) • ΔL_e = +4.6 nats ⇒ P_local = 99.0%
SPARSE vs. INTERVAL Shunt Masks Stage 2 Network Peeling
INTERVAL pays 2 ln L_eff + ln C(w, k) to specify start/end coordinates of a recombinant block of width w. SPARSE pays L_N(k) + ln C(M_pool, k) over the variable-site pool M_pool to index k scattered convergent sites or codons anywhere in the gene.
P_local(shunt) = 1 / (1 + exp(−ΔL_net)) • net MDL gain after endpoint and mask costs
Do my sequences or trees ever leave my computer? Privacy & Security
No. All alignment parsing, 64-site bit-plane tree induction, shunt discovery, and .bwz compression execute 100% locally inside your browser tab via Rust WebAssembly (bushwhacker_bg.wasm).
What is a .bwz file and how do I use it? Lossless Phylogenetic Archive
A .bwz file is a self-contained binary archive produced by BUSHWHACKER's causal phylogenetic arithmetic coder. It stores the induced tree, any reticulate shunts, and the complete multiple sequence alignment in a fraction of the space of gzip/xz, and can be dropped right back onto the BUSHWHACKER launchpad to restore both the alignment and tree bit-for-bit.
